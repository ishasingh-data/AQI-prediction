This project focuses on **predicting Delhi's Air Quality Index (AQI) using Machine Learning**. Historical air quality data was analyzed to identify patterns and develop a model capable of predicting AQI based on key air pollution parameters.

### Tools & Technologies

* Python
* Pandas & NumPy
* Scikit-learn
* TensorFlow 
* Matplotlib
* Machine Learning & Deep Learning

### Key Features

* Cleaned and preprocessed historical AQI data
* Analyzed major air pollutants such as **PM2.5, PM10, NO₂, CO, and SO₂**
* Applied multiple Machine Learning models for comparison
* Used time-series sequences for AQI prediction
* Developed a **GRU-based deep learning model**
* Evaluated the model using **MAE, RMSE, and R²**

### Objective

The main objective of this project is to use historical pollution data to build a predictive model that can help understand and forecast **Delhi's air quality trends**.
